# Classroom Focus Wall

A single-file HTML board for the classroom ViewSonic ViewBoard: period tabs, bell and IF schedules,
the SCCPSS 2026–27 calendar, Code.org lesson plans with automatic pacing, the Greenpower race countdown,
the per-car build checklist, lesson summaries with Up Next, and the rotating quote/fact strip.

- `index.html` and `focus-wall.html` are the same file. Open either in a browser; it works offline.
- Live copy: https://ravenracing.net/content/focuswall/
- Edits made on the board (Edit mode, checklists, build sign-offs) are saved in that browser only.
